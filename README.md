# Aman Roy — Personal Portfolio

Interactive portfolio for Aman Roy — Trader by Skill. Traveller by Heart.

## Run locally

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Build

```bash
npm run build
```

## Profile image

The profile image is stored as:

`public/aman-profile.png`

It is referenced in React as:

`/aman-profile.png`

This avoids Git LFS/path issues for the profile image.
